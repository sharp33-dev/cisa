1. 라우팅 프로토콜(Routing Protocol)의 정의

  • Routing이란 하나의 근원지에서 목적지로 internetwork를 통해 정보를 전달하는 과정
  • 대비되는 말로는 브리지(Bridge)이라는 용어가 있는데 그 개념은 비슷하나 Routing은 OSI 7 Layer에서 Network Layer(3계층)에서 일어나는 것이고, Bridge은 Datalink Layer(2계층)에서 일어나는 것이 차이점
  • 라우팅 프로토콜은 라우터 간 통신방식을 규정하는 통신규약

2. 라우팅 프로토콜 유형

▸ 원본 p.140 표: 프로토콜

프로토콜링크상태
RIP• Distance Vector 알고리즘을 사용하며, 라우팅 테이블은 매 30초 마다 브로드캐스팅을 통해 상호 정보 전달 • 홉(hop)수 제한(최대 16홉), VLSM(Variable Length Subnet Mask)
지원불가, Load Balancing 불가 • 네트워크 상태(대역폭, 지연시간, 부하량 등)는 고려하지 않음
IGRP• RIP의 문제점을 일부 개선한 방식(미국 시스코 사에서 RIP의 단점 보완을 위해서 개발) • 네트워크의 상태(대역폭, 지연시간, 부하량 등)를 고려 • 홉(hop)수 증가(최대 255홉), VLSM 지원불가, Load Balancing 가능
OSPF• Link State 알고리즘 사용 • 사용자 지정경로, 가장 경제적인 경로, 복수 경로 등 변화의 발생에 관한 정보가 RIP에 비해 빨리 전파 • 토폴로지에 관한 정보가 전체 라우터에서 동일하게 유지, VLSM 및 Load Balancing 가능
BGP• AS 간을 연결하는 EGP 방식, 규모가 큰 네트워크를 상호 연결 • TCP 기법을 사용하여, Path Vector 라우팅에 기반함

▸ 원본 p.141 표: 프로토콜

프로토콜링크상태

OSPF• Link Cost(링크 비용) • 링크 대역폭, 전송속도에 기초하여 계산되고, 16비트 Metric 값(1~65,535)으로 표현

거리벡터링크상태

• 인접 라우터에서 받은 라우팅 정보를 바탕으로 라우터에서 라우터까지 거리벡터 합• 각각의 라우터가 LSA를 모아서 자체적으로 다른 라우터까지 최소 경로 계산
• 주기적인 업데이트, 수렴속도 느림• 이벤트에 의해 변경이 일어나고 수렵속도가 빠름
• 인접 라우터에 라우팅 테이블을 복사• 다른 라우터에 링크상태 변경 정보 전송

▸ 원본 p.157: Mobile IPv6

1. Mobile IPv6의 정의

  • IPv6 주소를 사용하는 이동단말을 인증하는데 사용되는 IETF 이동 IP 표준(기존 IPv6에 이동성 헤더를 추가, 이를 통한 바인딩 관련 메시지 전송)
  • Neighbor Discovery와 Address autoconfiguration 기능을 이용하여 이동 단말이 이동하였을 때 자동으로 자신의 위치정보를 구성할 수 있도록 하였으며, 자신의 변환 위치 정보를 필요한 노드들에게 알릴 수 있도록 destination option을 추가함으로써, IPv4에서는 존재해야만 했던 일부 시그널 메시지들과 에이전트를 제거

2. Mobile IPv6의 특징

Q16. SDN(Software Defined Networking) 기술을 주도하고 있는 그룹 중 하나인 ONF(Open Networking Foundation)에서는 SDN 아키텍처를 애플리케이션 계층(Application Layer), 컨트롤 계층(Control Layer), 인프라스트럭처 계층(Infrastructure Layer)으로 구분했다. 이와 관련된 기술에 대한 설명으로 가장 거리가 먼 것은? (원본 p.194)
