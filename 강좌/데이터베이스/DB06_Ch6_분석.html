1. 데이터웨어하우스 (원본 p.2-7)

가. 데이터웨어하우스의 4대 특성

특성설명
주제 지향적(Subject Oriented)업무기능별로 관리되는 다수의 운영계 데이터 중 전사 관점의 의사결정에 필요한 특정 주제의 데이터만 저장
통합적(Integrated)전사적 데이터 표준화를 통해 정합성과 물리적 통일성을 갖춘 구조. 운영계 데이터 획득 시 통합을 위한 변환 작업 수행
시계열적(Time Variant)과거·현재 경향 분석 및 미래 예측을 위해 데이터를 Snapshot 형태로 오랜 기간 보유해 시간 경과에 따른 변화를 파악 가능
비휘발성(Nonvolatile)한번 적재되면 삭제·수정이 불가능한 조회 전용 DB로, 각 시점의 데이터 이력을 모두 저장

데이터 웨어하우스는 운영 중인 DB의 성능에 영향을 주지 않고 별도로 데이터를 보존하며, 이관 과정에서 데이터 불일치를 찾아내어 제거하는 정제(Cleansing) 기능도 수행한다. 다만 스타 스키마 모델링 시에는 빠른 조회 성능을 위해 차원 테이블을 정규화하지 않으므로, "정규화된 테이블을 사용해 효과적으로 관리한다"는 설명은 데이터 웨어하우스의 장점으로 옳지 않다.

나. 팩트 테이블과 차원 테이블

구분설명
팩트(Fact) 테이블중심 테이블로서 관련성이 높은 Measure(정보 분석 목표를 관찰할 수 있는 측정 데이터: 금액·건수·시간 등)들의 집합
차원(Dimension) 테이블부속 테이블로서 각 팩트를 분석하는 관점. 복수의 속성을 가져 다양한 관점의 데이터 분석이 가능

다. 스타 스키마와 스노우플레이크 스키마

구분설명
스타 스키마(Star Schema)팩트 테이블과 차원 테이블로 분리해 설계하는 모델링 기법. 차원 테이블이 정규화되어 있지 않아 데이터 중복이 발생하지만, 조인 수가 적어 이해하기 쉽고 질의 성능이 좋음(단, 데이터 중복으로 인한 일관성 문제 우려)
스노우플레이크 스키마(Snowflake Schema)스타 스키마의 차원 테이블을 완전 정규화하는 모델링 기법. 데이터 중복이 적어 적재 공간을 절약할 수 있으나, 조인 횟수가 늘어나 성능 저하 우려 존재

데이터베이스는 트랜잭션 중심의 응용을 위한 것이고, 데이터 웨어하우스는 의사결정 지원을 위한 것으로, 과거 데이터를 더 많이 요구하는 시계열·동향 분석 작업에 더 적합한 읽기 전용(read-only)이자 비휘발성(nonvolatile) 데이터베이스다. "실시간으로 갱신되므로 소멸성이다"라는 설명은 비휘발성 특성과 반대되는 오답이다.

2. OLAP (원본 p.8-12)

가. OLAP 주요 탐색 기법

구분설명
Drill Down특정 분석 주제에 대해 높은 요약 수준에서 낮은 요약 수준으로 단계적으로 접근하는 탐색 기법(큰 단위→작은 단위 집계)
Roll Up특정 분석 주제에 대해 낮은 요약 수준에서 높은 요약 수준으로 단계적으로 접근하는 탐색 기법(작은 단위→큰 단위 집계)
Drill Across하나의 분석 주제에 대한 특정 분석 과정을 이용해 다른 분석 주제로 접근하는 탐색 기법
Pivot(Rotate)특정 분석 주제에 대해 분석 관점의 축을 바꾸는 탐색 기법
Slicing(슬라이싱)하나 혹은 그 이상의 축을 중심으로 셀들을 선택하는 탐색 기법
Dicing(다이싱)속성 값의 범위를 명시해 셀들의 부분집합(부분큐브)을 선택하는 탐색 기법 — 두 개 이상의 차원을 Slice하여 부분집합을 만드는 것으로도 설명됨

Translate(문자열 대체) 연산은 OLTP에서 사용하는 문자형 함수로, 데이터 웨어하우스의 기본적인 OLAP 연산에 해당하지 않는다는 점이 자주 출제된다.

3. 데이터마이닝 (원본 p.13-42)

가. 데이터마이닝의 특징과 기법 분류

주요 특징내용
대용량의 관측 가능한 자료시간 흐름에 따라 축적
컴퓨터 집약적 기법컴퓨터의 처리 속도·능력을 활용해 기존 분석 방법의 한계를 극복
경험적 기법(adhockery method)경험에 기초해 개발되어 수리적 특징이 규명되지 않은 기법도 존재
일반화(generalization)새로운 데이터에 얼마나 잘 적용되는가를 의미
업무 활용경쟁력 확보를 위한 의사결정 지원
구분설명
분류(Classification)이미 알려진 속성을 활용해 그룹의 특징을 부여
예측(Forecasting)미래 발생할 사건을 확률로 분석
군집(Clustering)유사한 특성을 지닌 데이터의 그룹을 분류해 패턴을 분석
일반화(Generalization)관련성이 강한 데이터 조합을 통해 패턴을 발견

데이터마이닝 기법은 신용카드 이상거래 탐지(Fraud Detection), DNA 구조적 패턴 분석, 장바구니 분석(Market Basket Analysis) 등에 활용되며, 단순한 온라인 주문시스템(Order Entry System) 구축은 OLTP 영역이라 데이터마이닝 응용과는 거리가 멀다.

나. 데이터마이닝 주요 기법

기법내용사례
의사결정나무(Decision Tree)과거 수집된 레코드를 분석해 존재하는 패턴(분류별 특성)을 속성 조합으로 나타내는 나무 형태의 분류 모형. 분석의 정확도보다 분석 과정의 설명이 필요한 경우 유용우수 고객 분류, 대출 심사, 질병 예측
신경망(Neural Network)인간 두뇌 세포를 모방한 개념으로 반복적 학습 과정을 통해 모형을 만들어가는 기법. 입력-출력 관계·비선형 모델 학습이 가능하나 결과 해석(설명)이 어려움우수 고객 분석, 연체자 예측, 카드 오용 방지
연관성 분석(Association)데이터 안에 존재하는 항목 간 종속 관계를 찾아내는 작업. 상품 거래기록(Historical) 데이터로부터 상품 간 연관성을 측정장바구니 분석(맥주와 기저귀)
연속 규칙(Sequence)연관 규칙에 시간 관련 정보가 포함되는 형태로 고객의 구매 이력 정보가 필요신차 구입 후 캠핑 장비 구매
군집화(Clustering)거리에 기반해 가까운 곳에 있는 데이터끼리 같은 군집으로 묶는 방법. N개 속성을 가진 레코드를 N차원 공간의 벡터로 표시했을 때 유사한 레코드는 서로 근접한다는 가정에 근거K-Means 알고리즘, 고객 세분화, 대리점 위치 결정

K-Means 군집화는 ① K개의 Seed를 임의로 결정 → ② 거리가 가장 가까운 점들을 하나의 군집으로 결정 → ③ 군집의 중심값을 재설정해 Seed 변경 → ④ 중심값이 변경되지 않을 때까지 반복하는 절차로 수행되며, 사전에 군집의 수(K)를 정해야 하고 속성이 다양할 경우 적용이 어렵다는 한계가 있다.

다. 연관규칙 — 지지도·신뢰도·리프트

지표정의공식
지지도(Support)전체 거래 항목 중 X와 Y를 동시에 포함하는 거래의 비율 — 전체적 구매 경향 파악S = P(X∩Y) = (X와 Y를 포함하는 거래 수) / (전체 거래 수)
신뢰도(Confidence)항목 X를 포함하는 거래 중 항목 Y가 포함될 확률 — 연관성의 정도 파악C = P(Y|X) = P(X∩Y)/P(X) = (X와 Y를 포함하는 거래 수) / (X를 포함한 거래 수)
리프트(Lift/Improvement)항목 X를 구매했을 때 그 거래가 Y를 포함하는 경우와 Y가 임의로 구매되는 경우의 비L = P(X|Y)/P(Y) = P(X∩Y) / (P(X)·P(Y))
Lift 값의미예
= 1두 품목이 서로 독립적인 관계과자와 후추
> 1두 품목이 서로 양(+)의 상관 관계빵과 버터
< 1두 품목이 서로 음(-)의 상관 관계지사제와 변비약

Apriori 원리에 따르면 항목집합 {A,B}가 빈발하지 않으면 항목집합 {A,B,C}도 빈발하지 않으며(항목 개수가 늘어날수록 발생 확률은 작아짐), 따라서 항목집합 {A,B}의 지지도는 {A,B,C}의 지지도보다 항상 크거나 같다. 신뢰도도 마찬가지 논리로, 규칙 {A,B}→{C,D}의 신뢰도는 P(A∩B∩C∩D)/P(A∩B)이고 {A,B,C}→D의 신뢰도는 P(A∩B∩C∩D)/P(A∩B∩C)이므로, 분모가 더 작은(항목 수가 적은) {A,B}→{C,D} 쪽의 신뢰도가 더 크거나 같다(반대로 서술하면 오답).

라. 거리 척도와 예측 모델링

데이터마이닝에서 군집 간 거리를 계산할 때 유클리드 거리(Euclid Distance)는 두 점 간 항목 차이 값의 제곱의 총합의 제곱근으로, 맨하탄 거리(Manhattan Distance)는 차이 값의 절대값의 총합으로 계산한다. 예를 들어 X=(5,4,2,6,1), Y=(4,5,5,4,2)일 때 유클리드 거리는 √(1²+1²+3²+2²+1²)=√16=4, 맨하탄 거리는 |1|+|1|+|3|+|2|+|1|=8이다.

예측 모델링(Predictive Modeling)은 목표 변수를 설명 변수의 함수 모델로 생성하는 작업으로, 이산형(범주형) 목표 변수에는 분류(Classification), 연속형 목표 변수에는 회귀(Regression)가 사용된다. 서술 모델링(Descriptive Modeling)에는 연관규칙, 순차 패턴, 군집화 분석 등이 포함된다.

💡 Tip · 분류(Classification) vs 군집화(Clustering) 혼동 주의이미 알려진 클래스 레이블로 데이터를 분류하는 모델을 찾는 것은 분류(Classification)이고(if-then 규칙·결정 트리·뉴럴 네트워크 등 활용), 클래스 내 유사도는 최대화하고 클래스 간 유사도는 최소화하도록 새로운 객체 그룹을 생성하는 것은 군집화(Clustering)다. 두 정의를 서로 바꿔 서술하는 것이 전형적인 오답 패턴이다. 또한 OLTP 시스템은 구매·제조·창고·은행·급여·회계 등 업무 처리를 지원하고, 데이터 웨어하우스가 분석·의사결정 지원을 담당한다는 역할 구분도 함께 기억해 둔다.

4. 정보검색 (원본 p.43-55)

가. 정보검색의 3대 요소

요소설명
데이터 집합검색 대상 데이터로, 일정한 스키마를 가진 DB형 데이터와 제목·본문·생성날짜 등으로 구성된 문서형 데이터(정형·비정형)로 구분
색인문서형 데이터 집합에 대해 각 단어별 문서 리스트를 생성. 일괄색인(batch indexing)과 점증색인(incremental indexing)으로 구분
랭킹입력된 질의에 가장 적합한 순으로 문서를 나열 — 질의와 문서의 유사성, 최신성, 문서 품질, 사용자 검색로그 등을 종합해 판단
표현검색 결과를 단순 리스트, 유사 결과 그룹화, 데이터 종류별 구분(이미지·블로그·웹문서) 등으로 제시
사용자 피드백검색 품질 개선에 활용 — 사용자가 직접 제공하는 명시적 피드백과 검색로그 기반의 암묵적 피드백으로 구분

나. 정밀도(Precision)와 재현율(Recall)

실제 정답 Positive실제 정답 Negative
검색 결과 PositiveTrue Positive(TP)False Positive(FP, Type Ⅰ error)
검색 결과 NegativeFalse Negative(FN, Type Ⅱ error)True Negative(TN)
구분정의공식
정밀도(Precision)검색된 문서들 중 관련 있는 문서들의 비율TP / (TP+FP)
재현율(Recall)관련 있는 문서들 중 실제로 검색된 문서들의 비율TP / (TP+FN)

예를 들어 검색된 문서 중 적합 문서가 75건(TP)·부적합 50건(FP), 검색되지 않은 문서 중 적합 문서가 45건(FN)·부적합 30건(TN)이라면, 재현율 = 75/(75+45) = 0.625, 정밀도 = 75/(75+50) = 0.6이 된다.

다. TF-IDF

구분설명
TF(Term Frequency)문서에서 해당 단어가 얼마나 나왔는지를 나타내는 값. 여러 번 나와도 1로 정의하거나, 값을 줄이기 위해 log 처리하기도 함
DF(Document Frequency)전체 문서들 중 해당 단어가 몇 개의 문서에 나타나는지의 비율(해당 단어가 나타난 문서 수/전체 문서 수)
IDF(Inverse Document Frequency)DF의 역수(전체 문서 수 / 해당 단어가 나타난 문서 수). 분모가 0이 되는 것을 막기 위해 보통 분모에 1을 더함

TF-IDF는 단어 빈도(TF)와 역문서 빈도(IDF)의 곱(TF × IDF)으로 계산한다. 예를 들어 문서 d에서 단어의 TF가 3이고 IDF가 0.3010이라면 TF-IDF = 3 × 0.3010 = 0.9030이다.

라. 규칙 기반 분류기(참고)

규칙 기반 분류기는 "if ~ then …" 규칙들의 집합을 사용해 항목들을 분류하는 방법으로, 둘 이상의 클래스를 포함하는 데이터 집합에서 한 번에 한 클래스씩 규칙을 획득한다. 분류 규칙의 품질은 적용범위(Coverage)—데이터 집합 D와 규칙 r: A→y가 주어질 때 규칙 r이 적용되는 D에 속한 항목들의 비율—와 정확성(Accuracy)—규칙 r이 적용되는 항목들 중 클래스 레이블이 y와 같은 비율—로 평가한다.
